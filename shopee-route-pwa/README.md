# Shopee Route PWA

Aplicativo web instalável para organizar entregas Shopee em Anápolis-GO.

## Publicação
O site é publicado separadamente do Gama Drive, a partir da pasta `shopee-route-pwa`, via GitHub Pages.

## Recursos
- Importação de planilha .xlsx com os 10 cabeçalhos Shopee.
- Contagem de pacotes e agrupamento de endereços iguais.
- Inclusão manual com validação geográfica em Anápolis-GO.
- Exportação Excel com uma linha por pacote e cabeçalhos Shopee.
- Exportação CSV agrupada para importação no Circuit.
- Dados salvos localmente no aparelho.

## Privacidade
A planilha modelo original não é publicada: ela continha dados de entregas reais. O Excel exportado é gerado no próprio navegador, mantendo os cabeçalhos originais e sem incluir dados de clientes no repositório.
